# Install this GitHub profile

1. Open https://github.com/new
2. Create a **public** repository named exactly `shrashtimittal`.
3. Add a README, or leave the repository empty.
4. Upload the contents of this folder (not the containing folder):
   - `README.md`
   - `assets/orbital-header.gif`
   - `assets/orbital-divider.svg`
   - `assets/orbit-mark.svg`
5. Commit to the default branch. GitHub will display the README on your profile.

## Before publishing
- Add your LinkedIn URL and a professional email if you want them displayed publicly.
- Add the exact public URL for your Smart CubeSat repository.
- Check every project description against the current repository implementation.
- Remove tools from the skills list if you are not comfortable discussing or demonstrating them.
- GitHub statistics cards are hosted by third parties and may occasionally be unavailable or rate-limited.

## Animation notes
The header is an original animated GIF. It uses a restrained palette, a slow satellite movement and subtle star twinkle. GitHub README files do not run arbitrary JavaScript or CSS, so GIF/SVG assets are used instead of webpage-style animations.
